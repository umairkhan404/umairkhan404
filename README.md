**Current project:** Building an Elastic Stack SIEM lab to understand how security logs move from endpoints into a monitoring platform.

**Lab environment**
- Virtualization: VMware Workstation
- SIEM and log analysis: Elasticsearch and Kibana
- Endpoint: Windows 11
- Log investigation: Windows Event Viewer
- Server: Ubuntu Linux VM

**Hands-on topics**
- Installing and running Elasticsearch and Kibana.
- Exploring Kibana Discover and searching events.
- Learning Elastic Workflows and conditional logic.
- Reviewing Windows logon events such as Event ID `4624` and `4625`.
- Working toward Windows log integration, detection rules, and alert investigation.

📌 *This is an ongoing learning project. I will add screenshots, configuration notes, and investigation walkthroughs as I complete each stage.*
